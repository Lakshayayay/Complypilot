# v2 — Document Chaser

**Status:** Outline. Planned in detail after v1 ships.

## Goal (draft)
The CA asks for a missing document; the owner uploads it from a WhatsApp link without logging in; the CA checks and approves it.

## Scope ideas (from PDP Modules 2 and 3)
- A document checklist for each client and month.
- WhatsApp request with a secure upload link that expires.
- A no-login mobile upload page that can never show existing files.
- CA review screen: approve or reject (a rejection asks the owner again).
- Filing done → WhatsApp message with the receipt.
- AI: sort and label uploaded documents automatically; a human confirms.
