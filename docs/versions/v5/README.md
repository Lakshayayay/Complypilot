# v5 — Credit Passport

**Status:** Outline. Planned in detail after v4 ships.

## Goal (draft)
The owner shares a verified compliance and finance profile with lenders to get working capital (money to run the business day to day).

## Scope ideas (from PDP Module 6)
- Credit passport: filing record, tax payments, verified sales history and factory compliance status in one profile that lenders can verify.
- Lender connections: OCEN (India's open credit network), Account Aggregators (consent-based bank data sharing), TReDS (invoice discounting exchanges). These need lending partners and must follow RBI rules. Re-check at planning (UNVERIFIED).
- AI: a readiness score that explains its reasons.
