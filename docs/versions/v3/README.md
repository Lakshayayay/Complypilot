# v3 — Owner Console + Factory Layer

**Status:** Outline. Planned in detail after v2 ships.

## Goal (draft)
The owner sees their compliance health and documents at a glance, and the factory questions work in more states.

## Already in v1
Owner login, the shared calendar, email reminders, the licence tracker, factory questions for Delhi and Haryana, and the AI factory type matcher.

## Scope ideas (from idea.md Modules 3 and 4)
- Health score (green / yellow / red).
- Document vault: past filings and certificates (Udyam, GSTIN, PAN), easy to share with banks.
- Factory questions for more states: pollution consents (CTE = consent to set up, CTO = consent to run), factory licence, fire NOC, boiler certificate, EPR (plastic/waste recycling duties). Note: CTO no longer expires (see `../v1/research/licences.md`).
- Early warnings to the owner months before a licence expires, with the papers needed to renew.
